# Woven Earth — 3D

An interactive 3D model of **Woven Earth**, a terracotta spool courtyard screen:
one handmade clay module, repeated and threaded on cord into a breathing partition.

Drag to orbit, scroll to zoom, and use the controls to change the number of
columns and rows, the offset of the weave, and to toggle the timber frame and cords.

Interior Design Studio · Assignment 04 · NCA.
